# ASMR 라이브러리 — DLsite 구매작 모바일 플레이어

본인이 DLsite에서 **구매·다운로드한 음성 작품**을 PC에 모아두고,
폰에서 같은 Wi-Fi로 접속해 카드형 라이브러리 UI로 듣는 로컬 웹앱입니다.
파일은 PC 밖으로 나가지 않으며, 원본을 변환 없이 그대로 재생합니다(무손실).

## 준비물

- Windows PC + [Python 3.10 이상](https://www.python.org/downloads/)
  (설치 시 **"Add python.exe to PATH"** 체크 필수)
- 폰과 PC가 같은 Wi-Fi에 연결되어 있을 것

## 시작하기

1. **작품 넣기** — 구매작 압축을 풀어 `works\` 폴더에 **작품별 폴더째** 넣습니다.

   ```
   works\
   ├─ RJ01234567\
   │   ├─ 01 트랙.wav
   │   ├─ 01 트랙.srt      ← 자막 (선택)
   │   └─ ...
   └─ RJ765432 아무 메모나 붙여도 됨\
       └─ mp3\ ...
   ```

   - 폴더명에 **RJ코드**가 있으면 표지·제목·태그·성우를 DLsite에서 자동으로 가져옵니다.
   - 하위 폴더 구조는 자유입니다. 오디오는 mp3/wav/flac/m4a/ogg/opus 등을 인식합니다.

2. **서버 실행** — `실행.bat` 더블클릭 (첫 실행 시 필요한 패키지를 자동 설치).
   창에 접속 주소가 표시됩니다.

3. **폰에서 접속** — 폰 브라우저 주소창에 표시된 주소를 **`http://` 까지 포함해서** 입력:

   ```
   http://192.168.x.x:8974
   ```

   접속되면 브라우저 메뉴에서 **"홈 화면에 추가"** → 앱처럼 사용.

### 처음 접속이 안 될 때

| 증상 | 해결 |
|---|---|
| `ERR_SSL_PROTOCOL_ERROR` | 주소가 `https://`로 열린 것. `http://`를 직접 붙여 입력하거나, 크롬 설정 → 개인 정보 보호 및 보안 → "항상 보안 연결 사용" 끄기 |
| 연결 시간 초과 | 첫 실행 때 Windows 방화벽 알림에서 **허용**을 눌렀는지 확인 (사설 네트워크). 폰과 PC가 같은 공유기인지 확인 |
| 예전 화면이 그대로 나옴 | 서버 창을 껐다가 다시 실행. 이전 서버 창이 살아있으면 먼저 종료 |

## 자막

오디오 파일과 **같은 이름**의 자막 파일을 작품 폴더 아무 곳(하위 폴더 포함)에 두면
자동으로 연결됩니다. `CC` 표시가 붙은 트랙이 자막 있는 트랙입니다.

- 지원 형식: `.srt`, `.vtt`, 그리고 **SRT 구조로 작성된 `.txt`**
  (타임코드 `-->` 가 없는 일반 txt는 자막으로 취급하지 않음)
- 인코딩: UTF-8, Shift-JIS, CP949, UTF-16 자동 인식
- 이런 파일명 변형도 인식: `트랙명.wav-subs.srt`, `트랙명.ko.srt`
- 같은 트랙에 자막이 여러 개면: **한국어(.ko) → 파일명 정확 일치 → srt > vtt > txt** 순으로 선택

## 자막 자동 생성 (선택)

서버가 켜져 있는 동안 `works` 를 감시해서, 한국어 자막이 없는 트랙의 자막을 자동으로 만듭니다.
새로 넣은 작품도 복사가 끝나면 알아서 처리합니다. **유료 API 를 사람의 확인 없이 호출하므로**,
사용 한도를 API 사이트에서 먼저 걸어 두세요.

> 이 기능은 가짜 API 응답으로만 시험했고 실제 API 로는 아직 돌려보지 않았습니다. 처음에는 서버 창을
> 지켜보세요. 시작 후 파일·폴더 이름도 바뀌므로 작품 폴더를 먼저 백업해 두는 것을 권합니다.

`server.py` 와 같은 폴더에 키 파일 두 개를 만들면 켜집니다. 환경변수 `ELEVENLABS_API_KEY`,
`OPENAI_API_KEY` 가 있으면 그쪽이 우선합니다.

```
elevenlabs_key.txt     받아쓰기 (ElevenLabs Scribe)
openai_key.txt         교정·번역·이름 번역 (OPENAI_MODEL, 기본 gpt-6-luna)
```

[ffmpeg](https://ffmpeg.org/) 가 PATH 에 있어야 큰 파일 분할과 판 대조가 동작합니다.

처리 순서:

1. 일본어·중국어 자막이 이미 있으면 받아쓰기 없이 번역만 합니다.
2. 없으면 받아쓰기 → AI 교정 → 번역을 거쳐 `트랙명.ja.srt`(중국어 음성은 `.zh.srt`)와
   `트랙명.ko.srt` 를 오디오 옆에 저장합니다. 언어는 자동으로 판별합니다.
3. SE 유무만 다른 판은 효과음 없는 판만 받아쓰고, 음성을 대조해 시각을 맞춰 다른 판에 나눠 씁니다.
4. 작품의 파일·폴더 이름을 한글로 바꿉니다. 재생 기록은 새 경로로 옮겨집니다.

번역 지시, 용어집, 교정 치환은 앱의 ⚙ 설정에서 입력합니다. 작품별 설정은 작품 폴더에
`번역지시.txt`, `용어집.txt`('원문 = 번역'), `교정치환.txt`('오역 = 수정')를 두면 됩니다.

- **건너뛰기:** 대사가 없는 트랙은 옆에 빈 `트랙명.ja.srt` 를 만들면 처리하지 않습니다.
- **다시 만들기:** `.ko.srt`, `.ja.srt` 를 지우고 서버를 다시 켭니다.
- **이름 번역 끄기:** 서버를 켜기 전에 환경변수 `ASMR_TRANSLATE_NAMES=0` 을 설정합니다.
- **이름 되돌리기:** 서버를 끄고 `python subgen.py undo RJ01234567` 을 실행합니다.
  되돌린 작품은 자동으로 다시 바꾸지 않습니다. `cache/name_log.json` 을 지우면 되돌릴 수 없습니다.
- **실패 알림:** 서버 창의 빨간 경고와 앱 위쪽 빨간 배너로 표시됩니다. 앱에서 `확인` 을 누를 때까지 남습니다.
- **요금 보호:** 트랙 하나는 서버 실행당 한 번만 시도합니다. 키·한도 오류가 나면 1시간 멈춥니다.

## 제목 번역 (선택)

DLsite에서 받아온 일본어 제목을 한국어로 자동 번역합니다. **키가 없어도 앱은 정상
동작하며**, 제목만 일본어 원문으로 남습니다(서버 창에 안내가 뜹니다).

키를 넣으려면 아래 중 하나를 앱 폴더에 텍스트 파일로 저장하세요. 둘 다 있으면
Gemini를 먼저 쓰고 실패하면 DeepL로 넘어갑니다.

| 파일명 | 발급처 | 비고 |
|---|---|---|
| `gemini_key.txt` | [Google AI Studio](https://aistudio.google.com/apikey) | 카드 등록 불필요 |
| `deepl_key.txt` | [DeepL API Free](https://www.deepl.com/pro-api) | 월 50만 자, 카드 등록 필요 |

- 파일에는 키 문자열 한 줄만 넣습니다. 서버 재시작 없이 바로 적용됩니다.
- 환경변수 `GEMINI_API_KEY` / `DEEPL_API_KEY` 로 넣어도 됩니다.
- 모델을 바꾸려면 환경변수 `GEMINI_MODEL`. 쓸 수 있는 모델 목록은
  `python meta_repair.py --models` 로 확인합니다.
- 번역이 실패한 제목은 표시만 남겨두고 다음 접속 때 자동으로 다시 시도합니다.
  한 번에 정리하려면 `python meta_repair.py --apply`.

## 사용법

**라이브러리** — 카드를 탭하면 작품 상세로. 상단에서 검색(제목·서클·성우·태그·RJ코드)과
정렬(번호순/최근 추가순)이 가능합니다.

- **이어 듣기**: 맨 위 카드를 탭하면 마지막으로 듣던 트랙이 그 위치에서 이어집니다.
- **즐겨찾기**: 작품 상세의 ♡ 버튼으로 등록, 헤더의 ♥ 버튼으로 즐겨찾기만 모아 보기.
- **태그 필터**: 상세 화면의 장르·성우 칩을 탭하면 그 태그로 필터링.
- **진행률**: 끝까지 들은 트랙이 기록되어 카드에 진행률 바와 "3/8 들음"이 표시됩니다.
- **트랙 보기 3모드**: 목록 / 폴더 그룹 / **탐색**(폴더를 한 단계씩 이동, 이미지·txt도 열람).
  폴더 선택이 게임 진행인 어드벤처형 작품용으로, 재생 큐도 현재 폴더로 한정되고
  마지막 탐색 위치를 작품별로 기억합니다.

**플레이어** — 트랙을 탭하면 재생되고 하단에 미니 플레이어가 생깁니다. 미니 플레이어를
탭하면 전체 화면 플레이어가 열립니다.

- **보기 모드** (상단 `전체/표지/자막` 버튼): 전체 UI ↔ 표지+자막만 ↔ 자막만 순환.
  미니멀 모드에서는 화면을 탭하면 재생/일시정지.
- **설정** (`Aa` 버튼 또는 라이브러리 헤더의 `⚙`): **테마**(다크 / OLED 검정 / 라이트)와
  자막 크기(12~44px)·색상(프리셋 5색 + 자유 선택)을 조절합니다.
- **몰입 모드** (`⛶` 버튼): 상태바·주소창까지 포함해 모든 UI를 숨기고 표지와 자막만
  남깁니다. `전체` 보기에서는 재생바와 시간이 함께 남습니다. 화면을 한 번 탭하면
  상단바가 3초간 나타나고, `⛶`를 다시 누르면 해제됩니다.
  (아이폰 사파리는 전체화면 API를 지원하지 않아 앱 UI만 숨겨집니다)
- **자막 전체보기** (`≡` 버튼): 전체 스크립트를 보면서 줄을 탭하면 그 위치로 이동.
- 배속(0.8~2.0×), ±10초 이동, 트랙 연속재생(`연속` 버튼으로 켜고 끄기).
- 상단바에는 **현재 재생 중인 트랙명**이 표시됩니다(보기 모드와 무관).
- 트랙이 자동으로 넘어가면 화면 아래에 새 트랙명이 잠깐 표시됩니다.
- 시간이 겹치는 자막(다중 화자)은 위아래로 같이 표시됩니다.
- 가로 화면에서는 표지/자막 좌우 분할 레이아웃으로 전환됩니다.
- **이어듣기**: 트랙별 재생 위치가 자동 저장되어 다음에 이어서 재생.
- 잠금화면·이어폰 버튼으로 재생/일시정지/트랙 이동 가능.

## 참고

- 메타데이터·표지는 처음 한 번만 DLsite에서 받아 `cache\`에 저장합니다(이후 오프라인 동작).
  태그는 DLsite 공식 한국어 명칭, 일본어 제목은 기계번역이라 어색할 수 있습니다.
  특정 제목을 고치려면 `cache\meta\RJxxxxxx.json`의 `title` 값을 직접 수정하고
  `title_orig`에 원문을 넣어두면 다시 번역하지 않습니다.
- 포트를 바꾸려면 환경변수 `ASMR_PORT`, 작품 폴더 위치를 바꾸려면 `ASMR_WORKS_DIR`를
  설정하세요.
- 이 앱은 개인이 정당하게 구매한 파일을 본인 기기에서 재생하는 용도입니다.
  구매작 파일이나 서버를 타인에게 공개하는 것은 저작권 침해가 될 수 있습니다.
